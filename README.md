# Leakage-audited multi-ion insertion-electrode learning

This clean-room repository contains the computational workflow and selected evidence for a physics-constrained, leakage-audited multi-ion insertion-electrode machine-learning study with a sodium-ion case study and an original Quantum ESPRESSO spot check.

The repository excludes private caches, credentials, pseudopotential files, restart files, unrelated historical projects, and inherited Git history. The raw sodium Materials Project acquisition JSON is regenerated at runtime when authorized access is available and must not be replaced by a processed CSV.
