# Start here: upload this cleaned tree with GitHub Desktop

This folder has been cleaned for the existing repository. Do **not** create a new GitHub repository from this ZIP.

1. Keep your current working folder as a backup.
2. In GitHub Desktop choose **File → Clone repository**.
3. Clone `efatme/leakage-audited-multion-electrode-ml.v1` to a new local folder.
4. In GitHub Desktop choose **Current branch → New branch** and create:
   `paper/cmt-stage-learnability`
5. Close Jupyter notebooks that are editing the repository.
6. Copy **all contents inside this cleaned folder** into the cloned repository folder. Choose **Replace/Merge** when Windows asks.
7. Return to GitHub Desktop. Review the Changes list, then commit with:
   `Add frozen CMT stage-dependent learnability analysis`
8. Click **Publish branch** or **Push origin**.

Do not merge the branch to `main` until the uploaded branch has been checked in the GitHub web interface.

More detail: `documentation/GITHUB_DESKTOP_UPLOAD_GUIDE.md`.
